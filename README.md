# yougile-hermes-skill

Скилл для [Hermes Agent](https://github.com/NousResearch/hermes-agent): конвенции работы с карточками и CRM-сделками YouGile через MCP-сервер `yougile`.

Содержит принципы и правила работы с инструментами: какой тул для чего, подводные камни схемы, модель CRM, порядок тестовой проверки записи. Проектные данные (ID досок, названия клиентских проектов) сюда не входят.

## Установка

```bash
hermes skills install degin/yougile-hermes-skill/skills/productivity/yougile-tasks
```

Для работы нужен MCP-сервер YouGile, подключённый в Hermes.
